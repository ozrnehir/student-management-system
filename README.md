# 🎓 Student Management System (C++)

A console-based **Student Management System** developed in C++, designed to demonstrate core software engineering principles such as **data structures, modular programming, and CRUD operations**.

---

## 🚀 Overview

This project allows users to efficiently manage student records through a simple **command-line interface**. It focuses on clean structure, usability, and fundamental backend logic.

---

## ✨ Key Features

- Add new student records  
- View all students  
- Search students by unique ID  
- Update existing student information  
- Delete student records  
- Dynamic data handling using STL  

---

## 🧠 Concepts Applied

- Object-like data modeling using `struct`  
- Dynamic containers (`vector`, `unordered_map`)  
- Modular programming with functions  
- CRUD operations (Create, Read, Update, Delete)  
- User input handling and menu-driven systems  

---

## 🛠️ Tech Stack

- **Language:** C++  
- **Libraries:** Standard Template Library (STL)  

---

## ▶️ Getting Started

### Compile:
```bash
g++ studentsystem_main.cpp -o student_system
```

### Run:
```bash
./student_system
```
